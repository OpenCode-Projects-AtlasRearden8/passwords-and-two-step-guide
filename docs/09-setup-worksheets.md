# 9. Setup Worksheets

Print these (button at the top of this page, or Ctrl+P). They're designed to
fill in with a pen, one per sitting, no laptop needed. Keep your filled sheets
in the same physical folder as your backup codes — see
[chapter 4](04-backup-codes.md).

## Worksheet E — Breach response card

Keep this card in the same folder; pull it out any time an alert arrives.
(Read [the calm version](06-after-a-breach-alert.md) first; this is the
cheat-sheet on the day.)

```
1. Don't click links in the alert. Go to the site myself.
2. Change that password. Sign out all sessions.
3. Did I reuse that password anywhere else?  Y / N  → change those too.
4. 2FA on?  Y / N → turn on. Regenerate backup codes.
5. Check unknown sign-ins / devices / app grants. Revoke strangers.
6. Money/identity involved? → check 3 months of activity; consider credit freeze.
7. Date: ______  Site: ____________  What leaked: ______________
   What I did: _______________________________________________
```

## Worksheet F — The three-month glance checklist

The whole seasonal ritual on one card. It takes 20 minutes if you've done the
evening once.

- [ ] Any important account still without 2FA? (do one)
- [ ] Backup codes still findable in their folder?
- [ ] Vault export still where expected?
- [ ] Trusted-person arrangement still true to my life?
- [ ] Try a passkey sign-in if any account is passkey-ready.
- [ ] "Why do I still have this?" accounts: close at least one.
- [ ] Write the date and next glance date: __________ → __________
